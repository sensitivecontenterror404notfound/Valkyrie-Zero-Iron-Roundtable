08How to Play — Cara Menghidupkan & Lepas Landas
1. ENGINE START — SHIFT+E / tombol ENG ON. Mesin mulai spooling (~4 detik).
2. N1 SPOOL — tunggu N1 ≥ 20% (idle 24%). Suara mesin hanya berbunyi kalau mesin ON.
3. PARKING BRAKE OFF — SHIFT+B / tombol PARK. Pesawat tidak akan bergerak selama rem parkir SET.
4. FLAPS 1 — ] / tombol FLAP (15°). Flaps 2–3 untuk pendaratan.
5. THROTTLE 100% — tahan SHIFT / tombol THR +. CTRL / THR − untuk mengurangi.
6. TAKEOFF ROLL — kecepatan naik ke ~115 KT (dengan flaps) / ~135 KT (tanpa flaps). Jaga di tengah runway.
7. ROTATE — pada ~115 KT tarik W / stick ke belakang pelan-pelan sampai hidung naik.
8. GEAR UP — setelah positif climb (VSI naik), tekan G / tombol GEAR.
KAMERA 360° — tekan 6 untuk free orbit, atau drag mouse / jari di mana saja di layar (di luar tombol) — kamera berputar 360° dan pesawat tetap terbang normal. C ganti kamera, Z/U / WHEEL / pinch untuk zoom, O reset. Mode kamera + zoom terlihat di bar bawah HUD.
DI DALAM GAME — 8 langkah di atas muncul sebagai kotak panduan di layar sampai kamu airborne; ketuk kotaknya untuk menyembunyikan. Tombol CHK membuka landing checklist, PARK melepas rem parkir.
